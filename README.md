# 🏥 hzb_khovrino - Ховринская заброшенная больница
Карта **Ховринской заброшенной больницы (ХЗБ)** для **s&box** — реконструкция знаменитого московского недостроя с тремя “лучами” и центральным узлом (тот самый силуэт, который многие помнят по фото/роликам).

> Проектное название объекта: **Городская клиническая многопрофильная больница** *(проект на 1300 коек)*  
> Локация: Москва, район Ховрино — **ул. Клинская, 2**

## 🎯 Идея проекта
Реальную ХЗБ снесли, но у неё осталась **форма, атмосфера и легенда**.  
Моя цель — перенести **“дух места”** в цифровой мир.
